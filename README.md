# NetTopology — ІС топологій локальних мереж

Навчальний вебзастосунок українською мовою.

## Запуск
1. Розпакуйте архів.
2. Відкрийте `index.html` у сучасному браузері (Chrome, Edge або Firefox).
3. Інтернет-з'єднання для роботи не потрібне.

## Реалізовані модулі
- Огляд системи.
- Конструктор із візуалізацією топологій «Зірка», «Шина», «Кільце», «Дерево», «Комірчаста».
- Порівняння переваг, недоліків, складності та стійкості.
- Калькулятор орієнтовної вартості обладнання.
- Теоретичний довідник.

## Примітки
Це перша робоча версія. Візуальні схеми генеруються програмно на SVG. Розрахунок вартості є навчальною оцінкою, а не комерційною пропозицією.


## Доданий розділ курсового проєкту
У вкладці «Матеріали курсового» розміщено вступ, аналіз варіантів, опис алгоритмів, структуру програми, тестові сценарії, висновки та список джерел за структурою методичних рекомендацій. Тестові сценарії потрібно фактично виконати й зафіксувати скриншотами перед поданням роботи.
